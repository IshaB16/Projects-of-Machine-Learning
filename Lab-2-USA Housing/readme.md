# Lab 2 - USA Housing Dataset

## Aim

To study and apply data preprocessing and data analysis techniques on the USA Housing dataset.

## Dataset

USA Housing Dataset

The dataset contains information related to housing properties in the USA and their corresponding prices.

## Objectives

- To load and explore the USA Housing dataset.
- To understand the structure and characteristics of the dataset.
- To perform basic data preprocessing.
- To analyze numerical and categorical attributes.
- To study the relationship between different housing features and house prices.
- To prepare the dataset for further machine learning analysis.

## Tools and Technologies Used

- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset Features

The USA Housing dataset contains features related to properties such as:

- Average Area Income
- Average Area House Age
- Average Area Number of Rooms
- Average Area Number of Bedrooms
- Area Population
- Price
- Address

## Steps Performed

1. Imported the required Python libraries.
2. Loaded the USA Housing dataset.
3. Displayed the first few records of the dataset.
4. Checked the dataset structure and data types.
5. Checked for missing values.
6. Performed descriptive statistical analysis.
7. Visualized the data using suitable plots.
8. Analyzed relationships between housing features and price.
9. Prepared the dataset for machine learning analysis.
