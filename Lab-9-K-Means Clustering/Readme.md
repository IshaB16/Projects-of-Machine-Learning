## Algorithms Implemented

### 1. K-Means Clustering
K-Means is an unsupervised machine learning algorithm that divides data points into a predefined number of clusters based on similarity. It assigns data points to the nearest cluster centroid and updates the centroids until the clusters become stable.

### 2. Hierarchical Clustering
Hierarchical Clustering is an unsupervised machine learning algorithm that groups similar data points into a hierarchy of clusters. It uses a dendrogram to represent the merging of clusters.
